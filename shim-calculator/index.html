What is Shim Calculator?

A technical tool for suspension valving decisions

Shim Calculator helps tuners compare stack changes before committing to a build. It turns shim dimensions, stack order and configuration into clearer damping direction so workshop changes become more structured.

Who is it for?

  • Suspension tuners comparing valving options
  • Engineers modelling damping behavior
  • Workshop owners building repeatable setups
  • Race teams developing faster test plans
  • Advanced riders learning shim stack behavior

How it works

Compare changes against damping direction

Enter a stack, define the valve context, compare variations and review the predicted force versus velocity behavior.

Compression stack analysis

Study low-speed support, mid-speed control and high-speed blow-off direction.

Rebound stack analysis

Compare rebound control strategies before changing hardware.

Damping prediction

Use engineering calculations to see likely direction before a test session.

Force versus velocity curves

Visualise where a change adds support, frees movement or changes progression.

Engineering recommendations

Use structured prompts to decide what to test next.

Stack comparison

Compare baseline, softer, stiffer and crossover options side by side.

Diagrams

See how stack changes move the curve
